# Calendario

Calendario sincronizzato fra telefono Android, PC Windows e lo schermo **Trofeo LCD**.

- **Android**: [Calendario.apk](https://federicocarnevale2006-cpu.github.io/calendar/download/Calendario.apk)
- **Windows**: [Calendario-Setup.exe](https://federicocarnevale2006-cpu.github.io/calendar/download/Calendario-Setup.exe)
- **Web**: https://federicocarnevale2006-cpu.github.io/calendar/

Dati su Supabase (ogni account vede solo i propri eventi). Ad ogni modifica GitHub Actions ricompila APK, installazione Windows e versione web.
