# Calendario

Calendario sincronizzato fra telefono Android, PC Windows e lo schermo **Trofeo LCD**.

- **Android**: [Calendario.apk](https://github.com/federicocarnevale2006-cpu/calendar/releases/latest/download/Calendario.apk)
- **Windows**: [Calendario.exe](https://github.com/federicocarnevale2006-cpu/calendar/releases/latest/download/Calendario.exe) (un solo file, senza installazione)

Dati su Supabase (ogni account vede solo i propri eventi). Ad ogni modifica GitHub Actions ricompila APK ed exe per Windows (niente versione web).
